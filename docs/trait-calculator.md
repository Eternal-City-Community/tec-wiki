# Trait Calculator

Select up to **five positive**, **five negative**, and **one neutral** trait. The final trait balance must be **zero or less**. The calculator uses the published costs and descriptions from the [Traits reference](/traits/) and prevents documented mutually exclusive selections.

<div id="tec-trait-calculator"></div>

!!! note "About bonuses"
    The selected-effects summary displays documented bonuses and drawbacks. Percentages, conditional effects, and modifiers are **not** added into a speculative final stat: the wiki does not document all stacking rules. The calculator is a planning aid, not an in-game validation tool.
