Event submission should now be done via the web rather than through 
@submit-event.
If you'd like to submit an event, just visit:
http://eternal-city.com:8867/events/submit
You'll have to log in with your userid and password from your Skotos 
account.  On that page, you can enter your event request for the 
following week.  Your userid will be logged with your request, so if we 
have any questions or need to contact you, we can do so.
Please continue to make your blurb submissions in the format you see in the 
@event listings and mailings. Any suggestions for the new system or bugs
 with it should be @reported 
in-game.
