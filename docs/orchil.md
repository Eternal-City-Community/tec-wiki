# Orchil

Orchil is the official client for The Eternal City and can be accessed directly via the official web site for the game. It is a completely functional web client that lacks in functionality compared to other modern MUD games and web clients.


#### TEC Extender for Orchil:

Thanks to Thric3blinded (a valued community member) you can grab the TEC Extender from the Google Chrome Store or GitHub.  The extender adds the ability to run pre-built scripts or to build your own through an interface directly added within the extender. 

TEC Extender links: 
* [Chrome Web Store](https://chromewebstore.google.com/detail/tec-extender/aegdmagbofbclblaidikleeophbplmad?hl=en&pli=1)
* [GitHub](https://github.com/jdalley/tecext)

Do NOT download the extender from any websites other than the chrome web store or directly from Thric3blinded's GitHub page.
