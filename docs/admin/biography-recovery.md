# Character Biography Recovery

!!! warning "Not yet enabled"
    Administrator recovery remains disabled until the live publication, code rotation, and KV consistency safeguards are verified.

This page is intended only for GitHub **Eternal-City-Community organization owners**. Ordinary wiki editors cannot reset or revoke private biography editing codes.

Use **Inspect** to review the ownership-record status before taking action. **Reset** generates a new one-time code and invalidates the previous code once the change has propagated. **Revoke** disables player editing for that biography. Existing legacy biographies cannot be claimed using this interface.
