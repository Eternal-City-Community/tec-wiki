# Character Biography Recovery

!!! warning "Not yet enabled"
    This tool is still disabled while we finish testing. No codes can be reset or revoked yet.

Use this tool when a player has lost their biography editing code or when you need to stop someone from editing a biography.

**Who can use it?** Only owners of the **Eternal-City-Community** GitHub organization. Being a wiki editor alone is not enough.

## How to use it

1. Click **Authorize with GitHub** and sign in with your GitHub account.
2. Enter the character's **full name**, exactly as it appears on the biography.
3. Choose an action:
    - **Inspect ownership status:** Check whether the biography has a player editing record. **This does not change anything.**
    - **Reset private editing code:** Create a **new code** for a player who lost theirs. The **old code stops working**. Copy the new code and give it privately to the verified player.
    - **Revoke player editing:** **Turn off player editing** for that biography. The existing code will no longer work. This does **not** delete the biography.
4. Click **Run recovery action**. For Reset or Revoke, confirm the action when asked.
5. Read the result at the bottom of the tool.

!!! important "Before resetting a code"
    Confirm that the person asking for a reset is the actual player who owns the character. **Do not share the new code publicly.** The tool shows the new code only once.

This tool works only for biographies submitted through the player biography system. It cannot take over older biographies that were added manually.
