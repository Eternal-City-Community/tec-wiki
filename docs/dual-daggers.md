# Dual Daggers

### Skill Overview

Dual Daggers (insert small description later). Can be used with knives, daggers or dirks.

Knives and Cineran Knife Fighting cannot be used while dual-wielding. Skill Points cannot be shared between the three skillsets.

**For additional guidance on using this skill set, see the [Dual Daggers Combat Guide](/dual-daggers-combat-guide/)**.
